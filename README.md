🚗 Garage Management System

A full-stack web application designed to streamline garage operations, manage vehicle services, and improve customer experience through a digital platform.

📌 Overview

The Garage Management System helps garage owners efficiently handle:

* Customer bookings
* Vehicle service tracking
* Job status updates
* Billing and records

This project is built with a modern tech stack and follows a clean backend–frontend architecture.

✨ Features

👤 Customer Side

* Book vehicle service online
* Track service status
* View service history

🛠️ Admin / Garage Side

* Manage bookings and customers
* Update job status (Pending → In Progress → Completed)
* Maintain service records
* Dashboard for operations


🧱 Tech Stack

Frontend

* React.js
* Vite
* CSS

Backend

* Node.js
* Express.js

Database

* PostreSQL

⚙️ Installation & Setup

1. Clone the repository

```
git clone https://github.com/likithadc/garage-management-system.git
cd garage-management-system
```


2. Setup Backend

```
cd backend
npm install
npm start
```


3. Setup Frontend

```
cd frontend
npm install
npm run dev
```


🌐 Environment Variables

Create a `.env` file in backend folder and add:

```
PORT=5000
MONGO_URI=your_mongodb_connection
```
